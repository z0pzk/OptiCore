# OptiCore

Лёгкая системная утилита для Windows (C# .NET 8 + WPF), объединяющая три инструмента оптимизации в одном окне:

1. **Очистка RAM (в стиле Mem Reduct 3.x)** — сброс Working Set процессов, системного кэша и Standby-списков через Windows Native API (`NtSetSystemInformation` / `EmptyWorkingSet`), вручную и по порогу загрузки.
2. **Заморозка фоновых процессов с белым списком** — автоматическая приостановка (`NtSuspendProcess`) лишних программ при запуске игры и мгновенный возврат после выхода. Критические процессы Windows и белый список (Discord, Telegram, Steam и др.) защищены.
3. **Управление питанием и парковкой ядер CPU (в стиле ParkControl)** — при запуске игры переключает схему питания на максимальную производительность и отключает парковку ядер (`powercfg`), а после выхода возвращает сбалансированный режим.

## Как собрать через GitHub Actions

1. Загрузите все файлы из архива в свой репозиторий на GitHub (включая скрытую папку `.github/workflows/build.yml`).
2. Откройте вкладку **Actions** в репозитории и дождитесь завершения воркфлоу **Build OptiCore Windows EXE**.
3. Скачайте готовый `OptiCore.exe` из блока **Artifacts** (`OptiCore-Windows-x64`).
