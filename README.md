# OptiCore

Лёгкая системная утилита для Windows (C# .NET 8 + WPF), объединяющая оптимизацию памяти, заморозку процессов, управление питанием CPU, встроенный диспетчер задач и 20 твиков Windows.

## Возможности

* **Очистка RAM (в стиле Mem Reduct 3.x)** — сброс Working Set процессов, системного кэша и Standby-списков через Windows Native API (`NtSetSystemInformation` / `EmptyWorkingSet`), вручную и автоматически по порогу.
* **Встроенный диспетчер процессов** — сортировка по потреблению RAM или CPU, заметное выделение строки, заморозка/разморозка, завершение процессов и добавление в правила в один клик.
* **Заморозка фоновых процессов с белым списком** — автоматическая приостановка (`NtSuspendProcess`) лишних программ при запуске игры и возврат после выхода. Системные процессы Windows и белый список защищены.
* **Игровой режим CPU и точный таймер** — переключение схемы питания, отключение парковки ядер (`powercfg`), высокий приоритет (`High`) для игры и таймер Windows **0.5 мс** (`NtSetTimerResolution`).
* **20 твиков Windows** — безопасные игровые и системные твики (GameDVR, FSE, HAGS, планировщик, отключение Nagle/троттлинга, мышь 1:1, службы) + отдельно выделенные `[Осторожно]`-твики с оговорками и откатом в один клик.
* **Автозагрузка и трей** — тихий запуск с Windows через Планировщик заданий (без окна UAC) прямо в системный трей.
